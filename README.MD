# Pesquisa de Satisfação

Programa simples em Python que coleta a avaliação de 50 pessoas sobre um serviço.

## Tecnologias

![Python](https://img.shields.io/badge/Python-3.x-blue?logo=python&logoColor=white) 

## Como funciona

O programa solicita:

- Nome
- Idade
- Nível de satisfação

A satisfação deve ser informada usando:

- `E` para excelente
- `B` para bom
- `R` para ruim

No final, o programa mostra a quantidade de respostas em cada categoria.
